# Agent vs Prompt Simple Demo

This example demonstrates the fundamental difference between a 'prompt' and an 'agent' in AI systems. A prompt is a single, direct instruction that elicits a one-off response, lacking continuous state or autonomy. In contrast, an agent is an autonomous entity that continuously perceives its environment, makes decisions based on its goals, and takes actions over time, adapting to changes.

## Language

`python`

## How to Run

Save the code as `main.py`.
Run from your terminal: `python main.py`
